# test-seti/

Jüri Heyeti'nin modeli test etmesi için gereken test verisini bu klasöre koyun (şartname md. 5). Görev türünüze uyan biçim için [Test Seti Biçimleri](https://docs.t3gemstone.org/tr/competitions/t3-gemstone-challenge/edge-ai/test-set-formats) sayfasına bakın; bu klasör, oradaki `test-seti/` kök klasörüne karşılık gelir.

- Eğitimde kullandığınız veriyi buraya koymayın. Demo videosunda, test verisinin modelin başarımında avantaj yaratmadığı gösterilmelidir (şartname md. 5).
- Test verisi kişisel veri ya da kişiyi tanımlayabilecek bilgi içermemelidir (şartname md. 8).
