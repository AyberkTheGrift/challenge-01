# training/

Modeli eğitmek, ince ayar yapmak ve hızlandırıcı için derlemek (ONNX, TFLite vb. biçimlere dönüştürme dahil) için kullandığınız betikleri bu klasöre koyun. Eğitim kartta yapılmak zorunda değildir; betiklerin hangi ortamda çalıştığını ana README'nin "Model" başlığında belirtin.

Eğitim verisini bu klasöre koymayın. Veri setini paylaşmak zorunlu değildir; ancak niteliğini (kaynağı, boyutu, içeriği, etiketleme biçimi) ana README'nin "Model" başlığında belirtin.
